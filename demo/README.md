# MuseVis frontend demo

A standalone, responsive music discovery and visualizer presentation built with plain HTML, CSS and JavaScript. Includes sample tracks, mood filtering, search, favourites, a simulated playback timeline, transport controls and animated visualizer.

## Run

Open `index.html` directly in a browser, or serve the repository root with any static file server and visit `/demo/`.

This is a UI/UX demo: audio playback is simulated and does not stream copyrighted music. Spotify, Firebase, server APIs, lyrics lookup and real user accounts are not connected. No credentials are needed.

The original application source and `main` branch are preserved. This presentation lives on `frontend-demo-only`.
